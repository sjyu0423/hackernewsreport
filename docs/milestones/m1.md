## Ranking formula

```
rank = 0.45 * relevance_score + 0.40 * significance_score + 0.15 * hn_attention
```

`hn_attention` maps HN score into 1..5 via clamped log scale; missing HN → 2.5.

## Known limitations / M2 recommendations

1. Extraction still heuristic; some sites may remain noisy even after chrome stripping.
2. Qwen3 4B can over-score relevance on non-AI HN stories; consider category/source priors in M2 ranking.
3. On-demand only — M2 should add hourly delta selection + “new/meaningfully changed” filters.
4. Semantic near-duplicate clustering still needed across publishers.
5. Optional: allow `think=true` A/B for harder articles once latency budget is understood.
6. YouTube/video HN links remain thin-text; consider skipping extraction or labeling media-only items earlier.
