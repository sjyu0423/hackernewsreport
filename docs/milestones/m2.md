## Scope

Implemented:

- Story memory distinct from article rows (`stories`, `story_articles`, `story_events`)
- Conservative cross-source near-duplicate linking (prefer false negatives)
- Update classes: `NEW_STORY`, `NEW_SOURCE_SAME_STORY`, `MEANINGFUL_UPDATE`, `UNCHANGED`
- HN score-only changes are **not** meaningful updates
- M2 deterministic ranking with category priorities, AI signal, capped HN weight, diversity caps
- Hourly delta + daily digest reports with **independent** watermarks
- Legacy `ondemand` report mode preserved
- `--as-of` for deterministic report windows
- Failed persistence does not advance watermarks
- Fixtures + regression tests (including HN weather over-ranking)

Deferred (not M2):

- Background scheduler / cron
- Notifications / dashboard
- Semantic embedding-based clustering
- Cloud models / fine-tuning

## Ranking formula (documented)

```
rank = 0.35*significance
     + 0.25*relevance
     + 0.25*category_priority
     + 0.10*ai_signal
     + 0.05*hn_attention_capped
```

- Relevance and significance remain separate inputs.
- HN attention is capped (~3.5 max) and low-weighted.
- Low-priority categories (`weather`, `sports`, …) are penalized.
- Diversity: max 3 per source, max 4 per category in ondemand selection.
- Overrides via `QWENNEWS_CATEGORY_PRIORITIES=weather:1.0,models:5.0`.

## Known limitations / M3 recommendations

1. Near-dupe is conservative lexical/entity based — some true same-story pairs may stay split (by design).
2. `last_reported_at` is shared across modes; hourly/daily watermarks are independent, but story-level last-reported is a single field.
3. Breadcrumb chrome still appears in some DeepMind extracts (analysis-time cleanup helps but HTML chrome remains).
4. No scheduler yet — M3 should automate hourly/daily runs and notifications.
5. Consider embedding-assisted clustering only as a secondary signal with human-tunable thresholds.

## M3 recommendation

Add a local scheduler that runs `collect → analyze (cache-aware) → report --mode hourly`, plus optional daily digest delivery, while keeping watermarks crash-safe on persistence failures.
