# Milestone 4 — Local News Dashboard

## Goal

A polished, fast, **local-only** dashboard for reading AI-generated QwenNews briefings without changing the running hourly/daily LaunchAgents.

## Architecture

| Layer | Role |
| --- | --- |
| FastAPI (`qwennews.dashboard_api`) | Read-only JSON API over SQLite (`mode=ro`) |
| Next.js (`dashboard/`) | Dark editorial UI on `127.0.0.1:3000` |
| Existing SQLite | Source of truth for articles, stories, reports, backlog, runs |

- API binds **`127.0.0.1` only** (refuses `0.0.0.0`).
- No mutation endpoints; middleware rejects non-GET methods.
- No arbitrary file paths or SQL in query parameters.
- Outbound links validated to `http`/`https` only.

## Start / stop (development)

Terminal A — API:

```bash
cd /path/to/hackernewsreport
source .venv/bin/activate
python -m qwennews dashboard-api --host 127.0.0.1 --port 8765
# or: python -m qwennews.dashboard_api
```

Terminal B — UI:

```bash
cd /path/to/hackernewsreport/dashboard
npm install
npm run dev
# opens http://127.0.0.1:3000
```

Stop with Ctrl-C in each terminal. LaunchAgents are **not** started or stopped by the dashboard.

Optional env:

```bash
export QWENNEWS_DASHBOARD_DB=/absolute/path/to/qwennews.db
export NEXT_PUBLIC_QWENNEWS_API_BASE=http://127.0.0.1:8765
```

## Pages

1. **Today** — latest daily briefing (fallback to latest hourly/any with a clear label); story cards with summary / why-it-matters / source link.
2. **Hourly** — chronological hourly reports; separates developments vs no-update cycles.
3. **Stories** — M2 developing stories with first-seen / last-updated and linked sources.
4. **History** — filterable report browser + Markdown detail view.
5. **Status** — last-known watermarks/backlog/runs from SQLite; optional live Ollama probe (labeled).

## Tests

```bash
# API
pytest tests/test_dashboard_api.py

# Full Python suite
pytest && ruff check qwennews tests scripts

# Frontend
cd dashboard && npm run typecheck && npm run lint && npm test && npm run build
```

## Security notes

- External article fields are rendered as text (React escaping); Markdown history is shown in a `<pre>`, not as HTML.
- `javascript:` and non-http(s) URLs are stripped.
- Database path comes from config / `QWENNEWS_DASHBOARD_DB`, never from request input.

## Non-goals

- No cloud hosting, auth, or mobile app store release.
- No changes to LaunchAgent plists or schedules.
- No new model inference in the dashboard path.
