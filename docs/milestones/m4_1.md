## B. One-command dashboard startup

```bash
# Development (recommended)
python -m qwennews dashboard
# equivalent:
python scripts/run_dashboard.py
python scripts/run_dashboard.py --mode dev

# Production build mode (builds once if .next missing, then next start)
python -m qwennews dashboard --mode prod
```

Defaults: API `http://127.0.0.1:8765`, UI `http://127.0.0.1:3000`.

### Shutdown

Press **Ctrl-C** in the launcher terminal. The parent sends SIGTERM to API and Next children, waits briefly, then SIGKILL if needed. Log handles are closed after children exit.

### Port safety

If 8765 or 3000 is already occupied, the launcher **refuses to start** and **does not kill** the other process. Free the port yourself or pass `--api-port` / `--web-port`.

### Logs

- `data/logs/dashboard-api.stdout.log` / `.stderr.log`
- `data/logs/dashboard-web.stdout.log` / `.stderr.log`

### Troubleshooting

| Symptom | Fix |
| --- | --- |
| Port in use | `lsof -nP -iTCP:8765 -sTCP:LISTEN` (and 3000); stop that process yourself |
| `node_modules` missing | `cd dashboard && npm install` |
| API errors | Tail `data/logs/dashboard-api.stderr.log` |
| UI blank / fetch fail | Confirm API is up: `curl -s http://127.0.0.1:8765/api/health` |
| Wrong Python | Prefer `.venv`: `source .venv/bin/activate` |

No dashboard LaunchAgent is installed by M4.1.

## C. Reading experience

- Report detail pages render Markdown via `react-markdown` + `rehype-sanitize` (no raw `<pre>` dump).
- External links must be `http:` / `https:`; other schemes render as inert text.
- Story cards show source attribution, article published vs ingested times, and story first/last seen.
- Report rows / meta label **generated** (report time) separately from article publication.
- Loading / empty / error banners point at the one-command launcher.

Underlying report Markdown in SQLite is not rewritten.
