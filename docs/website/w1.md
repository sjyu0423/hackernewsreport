### Selection method

1. Read analyzed rows from the local production DB **offline** (not packaged).
2. Prefer grounded analyses (`sufficient` / `partial`) with public http(s) URLs.
3. Cover all five configured collectors when possible.
4. Replace private DB article ids with opaque `demo-NN` ids.
5. Export only public-safe fields (headline, URL, source label, timestamps, category, summary, why-it-matters, scores, evidence label, claims, limitations).
6. Do **not** export SQLite files, prompts, logs, local paths, or credentials.

## Known limitations

- OpenAI source URL may 403 automated clients; page remains the ingested canonical public URL.
- Snapshot is fixed; it will not refresh with local DB updates unless manually re-curated.
- Homepage preview shows three featured stories; full set is on `/demo/`.
- W1 does not automate fixture publishing from SQLite.
