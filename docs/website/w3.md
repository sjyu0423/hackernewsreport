- Dated test-suite snapshots (not live counters)
- Provenance links to public GitHub milestone docs (http(s) only)

## Known limitations

- M3 wall times are session observations, not a controlled cache-speedup experiment.
- Hardware details are omitted because they were not recorded in milestone docs.
- Comprehensive factual-accuracy / news-relevance evaluation remains future research.
- Explorer is pedagogical; it is not connected to SQLite or orchestration APIs.
