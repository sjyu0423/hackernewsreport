## Design choices

- Deep dive is optional and compact — not a second architecture tour or benchmark page.
- Examples are schematic / public-safe; no raw production prompts or DB dumps.
- Table/column names used are real conceptual names from `storage.py`, labeled as simplified teaching views.
- Reliability claims always distinguish mock/unit coverage from operational timer proof.

## Corrected claims

| Misreading | Correction |
| --- | --- |
| Schema “v5” backlog-era wording | Code stamps **schema_version = 6** |
| Shared `last_reported_at` alone | **story_report_state (story_id, mode)** for independence |
| Rich “uncertainty labels” | **evidence_sufficiency** + **limitations** only |
