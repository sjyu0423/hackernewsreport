# Public data export contract

This directory holds **explicitly selected, sanitized static fixtures** for the public QwenNews website demos.

It is **not** an automated export of the production SQLite database.

## Current snapshot (W1)

- File: `demo-briefing.snapshot.json`
- Docs: [`docs/website/w1.md`](../../../docs/website/w1.md)
- 8 curated stories from real local `qwen3:4b` analyses
- Opaque `demo-*` ids; no private DB primary keys

## Hard rules

1. **Never** commit or publish:
   - `*.db` / SQLite files
   - `.env` / secrets / API keys
   - LaunchAgent logs or private absolute machine paths
   - privately sensitive operator metadata
2. Demo items must link to **original public source URLs**.
3. Fixtures must be labeled as **recorded samples**, never as live model output generated by this static site.
4. Do not invent articles, rankings, citations, or benchmarks.
5. Prefer small JSON subsets reviewed by a human before publishing.

## Allowed fixture fields

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Opaque fixture id (`demo-NN`) |
| `headline` | yes | Public headline text |
| `summary` | yes | Sanitized Qwen summary |
| `why_it_matters` | yes | Sanitized explanation |
| `source_url` | yes | Canonical public http(s) URL |
| `source_name` | yes | Human-readable source label |
| `published_at` | no | ISO-8601 when known |
| `category` | yes | Analysis category |
| `evidence_sufficiency` | yes | sufficient / partial / insufficient |
| `relevance_score` / `significance_score` | yes | 1–5 from analysis |
| `key_claims` / `limitations` | no | Optional evidence detail |
| `disclaimer` | yes | Must state the sample is static / not live |

## Export procedure (manual)

1. Select candidate stories from a local DB or report **offline**.
2. Sanitize fields; drop private paths and operator notes.
3. Confirm every `source_url` is a public http(s) URL; record verification notes.
4. Write/update the snapshot file in this directory.
5. Keep demo UI copy explicit that the sample is recorded.
6. Do **not** wire automation that publishes DB contents.

## Runtime boundary

The public website:

- uses static export only
- must not call Ollama, FastAPI, or SQLite at runtime
- may only read committed fixture JSON at build time
