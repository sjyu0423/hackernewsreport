# Public data export contract

This directory holds **explicitly selected, sanitized static fixtures** for the public QwenNews website demos.

It is **not** an automated export of the production SQLite database.

## Hard rules

1. **Never** commit or publish:
   - `*.db` / SQLite files
   - `.env` / secrets / API keys
   - LaunchAgent logs or local absolute paths that identify a private machine beyond what is already public
   - privately sensitive titles, notes, or operator metadata
2. Demo items must link to **original public source URLs** when stories are shown.
3. Fixtures must be labeled as **recorded samples**, never as live model output generated by this static site.
4. Do not invent articles, rankings, citations, or benchmarks.
5. Prefer small JSON subsets reviewed by a human before publishing.

## Allowed fixture shape (future demos)

See `demo-briefing.schema.json` and the empty placeholder `demo-briefing.empty.json`.

Minimum fields for a demo briefing item:

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | Opaque fixture id (not a DB primary key dump) |
| `headline` | yes | Public headline text |
| `summary` | yes | Sanitized summary suitable for public display |
| `source_url` | yes | Canonical public http(s) URL |
| `source_name` | yes | Human-readable source label |
| `recorded_at` | yes | ISO-8601 timestamp of when the sample was captured |
| `significance` | no | Only if taken from a real analysis record |
| `disclaimer` | yes | Must state the sample is static / not live |

## Export procedure (manual)

1. Select candidate stories from a local DB or report **offline**.
2. Sanitize fields; drop private paths and operator notes.
3. Confirm every `source_url` is publicly reachable and appropriate.
4. Write a new fixture file under this directory.
5. Update demo UI copy to say the sample is recorded.
6. Do **not** wire automation that publishes DB contents.

## Runtime boundary

The public website:

- uses static export only
- must not call Ollama, FastAPI, or SQLite at runtime
- may only read committed fixture JSON at build time (or ship it as a static asset)
